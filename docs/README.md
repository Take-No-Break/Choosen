# Documentation

[Take-No-Break/Choosen](https://github.com/Take-No-Break/Choosen) is the public home for source code, Android/Windows downloads, illustrated guides, and scan results.

- [Download and screenshots](../README.md)
- [Architecture and build guide](ARCHITECTURE.md)
- [Contributors](../CONTRIBUTORS.md)
- [Checks and scan results](../SECURITY-CHECKS.md)
- [MIT license](../LICENSE)

The application uses C++ for the shared core, Svelte/TypeScript/JavaScript for its screens, and Java for the Android shell. The separate Flutter client uses Dart. Python verifies release downloads and is not the application's implementation language.
