# Choosen 📸

ปัดรูปแบบ Tinder แล้วค้นหารูปโปรดของคุณ!

[⬇ Android APK](https://github.com/Take-No-Break/Choosen/releases/download/v0.14.0/Choosen-Android-arm64.apk) · [⬇ Windows ZIP](https://github.com/Take-No-Break/Choosen/releases/download/v0.14.0/Choosen-Windows-x64.zip)

⚠️ เวอร์ชัน 0.14.0 ยังไม่ได้ตรวจด้วย VirusTotal ผลของเวอร์ชัน 0.12.0: VirusTotal ตรวจพบ Windows 2/71 รายการ ยังอยู่ระหว่างการตรวจสอบ ส่วน Android 0/68 [ดูผลการตรวจสอบ](../SECURITY-CHECKS.md)

## ชอบ ชอบมาก หรือข้าม?

เลือกโฟลเดอร์แล้วปัดดูรูป ♥ คือชอบ ★ คือชอบมาก หรือแตะปุ่มเพื่อให้คะแนนก็ได้

![ชอบ ชอบมาก หรือข้าม?](../images/swipe.jpg)

## รูปโปรดอยู่ตรงหน้า

ดูรูปทั้งหมด กรองตามคะแนน แล้วเปิดรูปที่สนใจให้ใหญ่ขึ้นได้

![รูปโปรดอยู่ตรงหน้า](../images/gallery.jpg)

## จัดอันดับจากความชอบของคุณ

เมื่อให้คะแนนรูป อันดับของโฟลเดอร์ก็เปลี่ยนตาม ดูได้ว่าโฟลเดอร์ไหนถูกใจคุณที่สุด

![จัดอันดับจากความชอบของคุณ](../images/ranking.jpg)

## พักแล้วเพลิดเพลินกับรูปโปรด

โหมดเล่นจะแสดงรูปอัตโนมัติและแสดงหลายรูปพร้อมกันได้ ส่วนสไลด์ให้คุณเลื่อนดูรูปในแนวนอนได้ตามใจ

![พักแล้วเพลิดเพลินกับรูปโปรด](../images/play.jpg)

*ภาพหน้าจอมาจาก Windows รุ่นปัจจุบัน ใช้เฉพาะภาพทดสอบที่สร้างขึ้น ไม่มีภาพส่วนตัว ส่วน Android จะปรับเค้าโครงตามความกว้างหน้าจอ*

รูปภาพและคะแนนเก็บไว้ในอุปกรณ์ แอปรองรับภาษาญี่ปุ่น อังกฤษ และโปรตุเกส

## ลองใช้เลย


- Android: ดาวน์โหลด APK ด้วยมือถือ เปิดไฟล์ แล้วอนุญาตให้เบราว์เซอร์ติดตั้งแอป ต้องใช้ Android 10 ขึ้นไปและ ARM64
- Windows: แตกไฟล์ ZIP แล้วเปิด Start-Choosen.cmd ต้องใช้ Windows 64 บิตและ Microsoft Edge
