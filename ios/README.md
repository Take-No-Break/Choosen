# iOS platform integration

Contains the Swift application shell, WKWebView integration, Photos access and Objective-C++ adapter for the shared C++ core. This platform is not included in the Android and Windows downloads.

- [project.yml](project.yml): XcodeGen project definition.
- [Choosen](Choosen/): application and core integration.
- [ChoosenUITests](ChoosenUITests/): simulator UI test sources.

Public downloads and installation instructions are available on the [project page](../README.md).
