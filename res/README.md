# Windows application resources

Windows resources embedded in Choosen.exe, including the application icon, version information and both bundled web interfaces.

- [choosen.rc](choosen.rc): Embedded interface files, icon and version definitions.
- [choosen.ico](choosen.ico): application icon.
- [icon-256.png](icon-256.png): raster icon asset.

The repository's [build script](../build.bat) includes these resources when producing Choosen.exe.
